# data-intelligence-solution-demo

> 根据 JD 或业务需求，快速生成一套完整的数据智能解决方案演示项目。

[English README](./README.en.md)

## 这是什么

`data-intelligence-solution-demo` 是一个面向 Codex 的 Skill，用来把一段模糊的 JD、岗位描述、招标要求、业务背景或产品需求，快速转成一套可讲、可演示、可扩展的数据智能解决方案 Demo。

它不是只输出一份泛泛的方案，而是会进一步组织成适合演示和交付的结构，包括：

- 能力解构
- 行业指标体系
- 页面模块设计
- Mock 数据字段
- 演示项目蓝图
- README / 讲解话术 / 扩展建议

适合用在面试作品、售前方案、业务汇报、数据产品原型和数据智能平台 Demo 搭建等场景。

## 解决什么问题

很多数据智能类需求都有同一个痛点：

- 输入是零散的，只是一段 JD 或一页业务描述
- 输出却要求很完整，要能讲业务，也要能落 Demo
- 既要像产品方案，又要像可运行项目骨架

这个 Skill 的目标，就是把这类“从 0 到 1”的方案组织工作标准化，帮助你更快得到一套像样、成体系、可直接拿去演示的数据智能项目。

## 核心能力

### 1. JD / 业务需求解构
自动识别行业类型、平台类型、目标角色、核心业务目标、关键指标与需要展示的数据智能能力。

### 2. 数据产品模块映射
把输入中的关键词自动映射为常见数据智能模块，例如：

- `MetricSystem`：指标管理
- `MetadataDashboard`：元数据治理
- `MemberPortrait`：客户画像
- `GrowthBrain`：增长实验
- `AICopilot`：AI 智能分析助手
- `Dashboard`：经营概览
- `RiskControl`：风控分析

### 3. 行业指标体系生成
内置多行业指标设计参考，可快速生成适合对应业务场景的指标盘与展示结构。

当前覆盖：

- B2B 平台
- B2C 电商
- 金融科技
- 教育平台
- SaaS / 企业软件
- 内容 / 社区平台
- 广告 / 商业化平台

### 4. 演示项目蓝图生成
输出完整的 Demo 项目建议，包括：

- 页面结构
- 模块划分
- 推荐视图
- Mock 数据字段
- README 建议章节
- 演示话术模板

### 5. 面试 / 售前 / 汇报友好
不仅生成“系统功能”，还会突出：

- 为什么这样设计
- 每个模块解决什么业务问题
- 适合怎样的演示路径
- 后续如何扩展到真实项目

## 典型使用场景

- 根据 JD 快速准备数据产品 / 数据智能岗位面试作品
- 根据客户需求快速搭建售前演示 Demo
- 根据业务描述生成 BI、指标体系、用户画像、增长实验类原型
- 为数据平台、指标平台、AI 分析助手等方向生成初始化方案
- 在短时间内搭建一个“既能讲业务、又能讲产品、还能讲实现”的项目骨架

## Skill 输出内容

当你提供一段 JD 或业务描述后，这个 Skill 默认会按以下结构组织输出：

1. 输入理解与默认假设
2. JD 能力解构
3. 业务指标体系
4. 演示项目功能模块
5. 页面与数据设计
6. 项目结构与实现计划
7. 演示话术
8. 后续扩展建议
