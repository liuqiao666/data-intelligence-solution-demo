# data-intelligence-solution-demo

根据 JD 或业务需求，快速生成一套完整的数据智能解决方案演示项目的 Codex Skill。

## 项目简介

`data-intelligence-solution-demo` 是一个面向数据产品、数据分析、售前方案、面试展示和业务汇报场景的 Codex Skill。它可以根据用户提供的 JD、岗位描述、招标要求或业务需求，快速拆解业务能力，自动映射数据智能产品模块，并生成一套完整的数据智能解决方案演示项目。

该 Skill 会围绕“业务理解、能力解构、指标体系、功能模块、演示数据、项目结构、演示话术”形成标准化输出，帮助用户把模糊的业务描述转化为可展示、可讲解、可开发的数据智能 Demo。

## 核心能力

### 1. JD / 业务需求解构
自动识别行业类型、平台类型、核心业务目标、关键指标和需要展示的数据智能能力。

### 2. 数据产品模块映射
将指标体系、元数据治理、客户画像、增长实验、AI 助手、经营分析、风控分析等关键词映射为具体演示模块。

### 3. 行业指标体系生成
支持 B2B、B2C 电商、金融科技、教育平台、SaaS、内容社区、广告商业化等行业指标设计。

### 4. 演示项目蓝图生成
输出经营概览、指标管理、元数据治理、客户画像、增长实验、AI Copilot 等页面结构与 Mock 数据字段。

### 5. 汇报与演示话术生成
自动生成适合面试、售前、业务评审、管理层汇报的演示路径和讲解重点。
